# COUNT+CARE IT Help Desk

Internes IT-Helpdesk-System zur Verwaltung von Support-Tickets.

## Technologien
- Python
- Flask
- SQLite
- HTML
- CSS

## Funktionen
- Login / Logout
- Dashboard
- Ticket-Erstellung
- Ticket-Bearbeitung
- Ticket-Löschung mit Bestätigung
- Prioritäten
- Zuständigkeiten
- Kommentare pro Ticket
- Such- und Filterfunktion

## Projektstatus
Prototyp für interne Support-Prozesse.
